# breslee1707.github.io

Personal portfolio of **Lê Ngọc Gia Huy (Le Ngoc Gia Huy)** — AI Engineer at Intel, co-founder of Code4life®.

Live: https://breslee1707.github.io/

## Design

*"Ochre & Ink"* — a technical catalogue printed on the ochre wall from the portrait: warm ink and paper grounds, one ochre accent, Archivo (with its width axis) for display, Spectral for text, JetBrains Mono for instrument read-outs. Every 3D moment draws something the work actually does:

- **Hero — Scan 01.** A six-axis arm (procedural three.js, analytic IK) sweeps a line laser over a depth-mapped point cloud of the portrait. Scrolling resolves it into the real photograph, which then opens up.
- **Work — Exhibits 01–05.** A sticky stage draws each project live: the agent loop, agentic retrieval, the arm inspecting a part, a LIDAR rover mapping a room, the stroke early-warning smartwatch.
- **Toolkit — The Die.** The stack as a silicon die that assembles from an exploded isometric view (CSS 3D, real DOM text).
- An aperture photo band, an experience rail, award plates and the Agent Lab replay.

Light and dark themes both meet WCAG AA contrast.

## Stack

- **Vite + React + TypeScript**, **Tailwind CSS v4** (tokens in `src/index.css`)
- **three.js + React Three Fiber** for the WebGL scenes (`src/three/`), **Lenis** for smooth scrolling
- Self-hosted fonts via `@fontsource`; `lucide-react` and `simple-icons` glyphs
- Prerendered at build time (`src/entry-server.tsx` → `scripts/prerender.mjs`) so crawlers get the full HTML

### How the 3D loads

WebGL code lives only in `src/three/` and is imported dynamically after hydration — and only when the browser has WebGL2 and the visitor hasn't asked for reduced motion or Save-Data (`src/hooks/useCan3D.ts`). Otherwise the page shows static fallbacks: the photograph in the hero, 2D line-art on the Work stage, a flat die. Add `?no3d` to the URL to preview the fallback. three.js is one lazy chunk (~250 KB gzipped) and never blocks first paint; canvases pause when scrolled out of view.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build + prerender to dist/
npm run preview  # preview the production build
```

## Edit content

All copy lives in **`src/data/content.ts`** — name, intro, projects (with their exhibit captions), experience, toolkit, FAQ and contact links. Components read from it. The FAQ is mirrored by the FAQPage JSON-LD in `index.html`; keep both in sync.

## Assets

- **Portrait:** `public/assets/portrait.webp` (1200 px) is the fast first-paint image; the full-resolution `portrait.jpg` (1792 px) is swapped in after load so the opened frame stays sharp on dense screens.
- **Point-cloud depth:** `public/assets/portrait-depth.webp`, generated by `scripts/portrait-depth.mjs` from MediaPipe's multiclass selfie segmentation. Re-run it if the portrait changes:

  ```bash
  npm i --no-save @mediapipe/tasks-vision playwright
  node scripts/portrait-depth.mjs
  ```

## Deploy

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and publishes to GitHub Pages.

> One-time setup: **Settings → Pages → Build and deployment → Source = "GitHub Actions"**.

Static content (the `edge-ai-projects/` notes, images) lives in `public/` and is served from the site root, e.g. `/edge-ai-projects/`.
