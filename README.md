# Personal Portfolio Draft

This is a lightweight static portfolio draft in English. It is designed to be easy to edit and free to host on GitHub Pages, Cloudflare Pages, Netlify, or Vercel.

## Files

- `index.html` contains the portfolio content and section structure.
- `styles.css` contains the responsive visual design.
- `script.js` handles the mobile menu, theme toggle, year, and copy email action.
- `assets/` contains local placeholder images.

## Edit Later

Replace the placeholder name, role, location, email, social links, project titles, and project descriptions in `index.html`. Replace the PNG images in `assets/` with your portrait and real project screenshots.

## Free Hosting Options

- GitHub Pages: upload these files to a repository and enable Pages from the repository settings.
- Cloudflare Pages: connect the repository and deploy as a static site with no build command.
- Netlify or Vercel: import the repository and keep the build command empty.
